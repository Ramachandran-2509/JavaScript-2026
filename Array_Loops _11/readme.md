# 📝 Todo List App

A simple Todo List application built using JavaScript.

## 🚀 Features

- Add new tasks with due date
- Display task name and due date
- Dynamic UI update
- Improved event handling using `addEventListener`

## 🆕 Recent Updates

- Initially used `onclick` for button actions
- Now updated to use `addEventListener` (best practice ✅)
- Initially used `for` loop to render tasks in the UI
- Updated implementation using `forEach` for cleaner and more readable code
- Improved UI update logic for better maintainability
- Clean and scalable code structure

## 🛠️ How It Works

1. Enter task name in the first input box  
2. Select due date in the second input box  
3. Click the **Add** button  
4. The task along with due date will be displayed below  

## 💡 Example

Task: Buy groceries  
Due Date: 2026-04-14  

👉 Output will be shown like:

- Buy groceries - 2026-04-14

## 🧑‍💻 Tech Stack

- HTML
- CSS
- JavaScript (DOM Manipulation)

## 📌 Learning Highlights

- Difference between `onclick` and `addEventListener`
- Handling user inputs
- DOM manipulation using loops (`for`)
- Optimizing UI updates (partial update instead of full re-render)
